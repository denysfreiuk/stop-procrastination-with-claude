# Правила для Claude Code у цьому vault

Це особистий щоденник навчання і звичок. Telegram-бот пише в ті самі файли протягом дня.
Мова нотаток — українська. Часовий пояс і шлях до vault задані в `.env` у корені репозиторію.

## Структура

```
Journal/Daily/YYYY-MM-DD.md    щоденні нотатки
Journal/Weekly/YYYY-Www.md     тижневі огляди (ISO-тиждень, наприклад 2026-W44)
Inbox/                         сирі записи, ще не розібрані
Learning/                      нотатки по темах: ML, English, Uni
Templates/                     шаблони Daily і Weekly
Dashboard.md                   статистика (Dataview)
Звички.md                      трекер звичок по днях (Dataview)
Слова на вивчення.md           таблиця слів, яку користувач вчить, і список «Уже в Anki» (веде /anki-from-notes)
```

## Головні правила

- Не видаляй і не переписуй записи користувача, навіть якщо вони здаються чернеткою чи з помилками.
- Новий текст дописуй у кінець потрібного розділу.
- Зберігай стиль користувача: короткі живі записи, без канцеляриту.
- Міняй у Properties лише потрібний ключ. Не переформатовуй frontmatter і не чіпай чужі ключі.
- Заголовки розділів не перейменовуй: бот і Dashboard шукають їх за точною назвою.
- `Templates/`, `Dashboard.md`, `Звички.md` і `CLAUDE.md` публічні: особистому там не місце.
- Журнал, `Inbox/` і `Learning/` приватні. Не додавай їх у git і не цитуй у публічних файлах.

## Щоденна нотатка

Нову нотатку роби лише з `Templates/Daily.md`.

| Property | Тип | Значення |
|---|---|---|
| `date` | дата | день нотатки |
| `focus_blocks` | число | блоків фокусу за день |
| `focus_minutes` | число | хвилин фокусу за день |
| `screen_time_min` | число | час екрана за день, хвилини |
| `tiktok_relapse` | так/ні | чи був зрив на тікток |
| `sleep_hours` | число | сон минулої ночі, години |
| `gym` | так/ні | чи було тренування |
| `gym_minutes` | число | хвилин у залі за день |
| `new_words` | число | нових слів за день |
| `energy` | число | енергія дня, 1–5 |
| `anki_done` | так/ні | чи зроблено картки з «Що вивчив» цієї нотатки |

Порожнє значення означає «не записано», а не нуль.

| Розділ | Хто пише | Формат запису |
|---|---|---|
| `## Фокус` | бот | `- 14:32 · 50 хв · ML` |
| `## Що вивчив` | бот, користувач | `- 14:32 текст` |
| `## Нові слова` | бот, користувач | `- borrow` або `- reluctant — речення чи місце, де зустрів` |
| `## Телефон / тікток` | бот, користувач | `- 22:10 зрив: причина` |
| `## Зал` | бот | `- 18:00 · 60 хв · ноги` |
| `## Їжа` | бот | `- 13:05 текст` |
| `## Нотатка дня` | бот, користувач | вільний текст |
| `## Підсумок` | `/journal` | короткий підсумок і 1 порада на завтра |
| `## Лог` | бот | `- 14:32 текст` |

## Визначення для статистики

- **День навчання:** `focus_minutes` більше нуля або є запис у `## Що вивчив`.
- **Стрік:** дні поспіль. Порожній сьогоднішній день стрік не обриває, а день без нотатки обриває.
- **Зрив на тікток сьогодні** обнуляє стрік днів без тіктока.
- **`anki_done`:** стосується лише `## Що вивчив`. Ставиться в `true` лише після того, як картки додано. Новий запис у `## Що вивчив` повертає `false`, тож під час `/anki-from-notes` пропускай те, що вже є в Anki.
- **`## Нові слова` — черга на Anki.** Слово чекає, доки воно (день і слово) не з'явиться в `## Уже в Anki` сторінки `Слова на вивчення.md`. Спершу воно йде в таблицю `## Вчу зараз`, а картки робляться, коли користувач її вивчив. Цю сторінку змінюй лише інструментами плагіна.

## Тижневий огляд

Нову нотатку роби лише з `Templates/Weekly.md`. Метрики тижня лежать у Properties, рахуй їх за щоденними
нотатками і не вигадуй значень: якщо даних немає, лишай поле порожнім.
